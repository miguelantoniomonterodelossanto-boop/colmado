# colmado
agencia de marketing para colmado

## Footer propuesto

El repositorio todavía no incluye una aplicación ni un sistema de estilos. Por eso, el footer se entrega como una pieza independiente en `footer.html` y `footer.css`, lista para adaptar al framework que el equipo elija.

### Integración

1. Copia el contenido de `footer.html` al final del componente o página principal.
2. Importa `footer.css` desde la hoja de estilos global o desde el componente.
3. Cambia `Colmado Click` por el nombre definitivo de la agencia.
4. Ajusta los enlaces `#...` para que coincidan con las secciones reales de la página.

El diseño usa HTML semántico, estilos responsivos y un verde profundo con acentos lima y naranja, asociado al comercio de barrio y a una marca cercana.
